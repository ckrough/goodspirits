# De-identification: case-tansy

Techniques are named in ISO/IEC 20889 terms. The source is one animal's shelter-management memo export, its volunteer walk notes, and foster notes.

| Field | Technique | Change |
|---|---|---|
| Animal name | pseudonymization | Replaced with "Tansy" in the record and the ideal |
| Other shelter dogs' names, a foster's cats | pseudonymization | Replaced with "Dog A" through "Dog L"; the cats unnamed |
| Shelter name and address | pseudonymization | Replaced with "Hollowbrook Animal Rescue"; address removed |
| Shelter ID, microchip number | suppression | Removed |
| Staff, volunteer, foster, and family names; the approved-walker list | suppression | Removed; entries name the role ("a volunteer", "her foster", "an older man in the family") |
| Calendar dates | generalization | Rewritten as weeks from intake |
| Date of birth, exact age | generalization | "young adult (about 3 years)" |
| Breed | generalization | "small mixed breed" |
| Shelter location names, a store name, a car model, a rideshare brand | suppression | Removed or replaced with a plain description ("an open area", "a shop", "a pet rideshare") |
| Feeding schedule, a cat-test video link | suppression | Removed |
| Diamond Dog program disclaimer | suppression | Shortened to the dog's support level |
| Published profiles and their page address | suppression | Removed from the record; the ideal Description is written from the record |
