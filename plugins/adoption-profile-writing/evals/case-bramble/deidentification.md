# De-identification: case-bramble

Techniques are named in ISO/IEC 20889 terms. The source is one animal's shelter-management memo export and its volunteer walk notes.

| Field | Technique | Change |
|---|---|---|
| Animal name | pseudonymization | Replaced with "Bramble" in the record and the ideal |
| Brother's name | pseudonymization | Replaced with "his brother" |
| Shelter name and address | pseudonymization | Replaced with "Hollowbrook Animal Rescue"; address removed |
| Shelter program name | pseudonymization | Replaced with "Senior Program" |
| Shelter ID, microchip number | suppression | Removed |
| Staff and volunteer names, memo authors | suppression | Removed; entries name the role ("a volunteer", "another volunteer") |
| Calendar dates | generalization | Rewritten as days from intake |
| Date of birth, exact age | generalization | "senior (about 10 years)" |
| Breed | generalization | "small toy-breed mix" |
| Shelter location names (building and room) | suppression | Removed |
| Feeding schedule, dental appointment | suppression | Removed as medical detail the profile does not use |
| Published profile and its page address | suppression | Removed from the record; the ideal Description is written from the record |
| Adult-only placement | generalization | The published profile's adult-only requirement is restated as a day-51 matchmaking note, since the memo export carries it nowhere else |
