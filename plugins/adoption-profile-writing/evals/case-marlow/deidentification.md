# De-identification: case-marlow

Techniques are named in ISO/IEC 20889 terms. The source is one animal's shelter-management memo export and its volunteer walk notes.

| Field | Technique | Change |
|---|---|---|
| Animal name | pseudonymization | Replaced with "Marlow" in the record and the ideal |
| Other shelter dogs' and the shelter cat's names | pseudonymization | Replaced with "Dog A" through "Dog F" and "Cat A" |
| Shelter name and address | pseudonymization | Replaced with "Hollowbrook Animal Rescue"; address removed |
| Shelter program names | pseudonymization | "Senior Program", "the trail-outing program" |
| Shelter ID, microchip number, ear-tattoo text | suppression | Removed |
| Staff and volunteer names, memo authors, the adoption advocate's name and email | suppression | Removed; entries name the role |
| Calendar dates | generalization | Rewritten as months from intake |
| Date of birth, exact age | generalization | "senior (about 8 years)" |
| Breed | generalization | "medium hound mix" |
| Intake injury | generalization | "Possible old wound in his shoulder" |
| Medication names and doses | generalization | "a calming medication before thunderstorms and fireworks" |
| Veterinary clinics, school, and town names; video and protocol links | suppression | Removed |
| Feeding schedule, medical expenses, vaccine dates, a vet-visit handling note | suppression | Removed as detail the profile does not use |
| Published profiles and their page address | suppression | Removed from the record; the ideal Description is written from the record |
